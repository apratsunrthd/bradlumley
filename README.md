# Brad Lumley Links

A polished, linktree-style landing page to browse Brad Lumley's professional work and cycling adventures.

## Preview

Open `index.html` in your browser or run a quick server:

```bash
python -m http.server 8000
```

Then visit http://localhost:8000/ to preview the page.
