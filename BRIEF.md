# BRIEF

## What this is

`bradlumley.com` is Brad Lumley's personal vanity domain. It used to be a
linktree-style page split between professional links and cycling ("TN Gravel
Dad") links. The cycling side stopped being maintained, so it was removed
(PR #4), and the domain was repositioned around two jobs:

1. **Canonical identity page** — a machine-readable "who is Brad Lumley" page
   (schema.org `Person` JSON-LD + real meta description) so search engines and
   AI answer engines have an authoritative source instead of guessing.
2. **Project launchpad** — a home base for the MVP side projects Brad
   prototypes with Claude Code. Each shipped project gets a subdomain
   (`projectname.bradlumley.com`) and a card in the "Lab" section, instead of
   a throwaway domain purchase per idea.

RefHealth Consulting (`refhealth.consulting`) already owns "hire me for
consulting" — this site is deliberately not a second version of that. No blog,
no content cadence: see HANDOFF.md for why.

## Current state

- Static single-page site (`index.html`), no build step, no framework.
- Hosted on GitHub Pages, custom domain via `CNAME` → `bradlumley.com`.
- Sections: Professional (LinkedIn, RefHealth Consulting, Email) and Lab
  (currently a placeholder — "Nothing shipped yet").
- Real headshot in place (`assets/`) for the avatar, OG/Twitter share image,
  and favicon/apple-touch-icon — no more placeholder initials avatar.
- Open Graph + Twitter Card meta tags added, so link previews (Slack,
  iMessage, LinkedIn) show a title/description/image.
- Person JSON-LD includes `image`, `email`, and `knowsAbout`; `jobTitle` is
  "VP, Data & Analytics" (chosen over vaguer executive-level phrasing —
  research showed standard concrete titles rank higher in recruiter search).
- Google Analytics wired in (`G-ZHGLL23Y0D`), auto-injected/maintained by
  `inject-ga.js` via a GitHub Action on every push to `main`.
- `sitemap.xml` is auto-generated by the same Action.

## Key decisions

- **No blog / content marketing.** Research (see PR discussion / plan file at
  time of this change) found weak, declining ROI for personal blogs as a
  networking tool in 2025-2026, and it's the one lever that needs Brad's own
  voice — not something worth building infrastructure around speculatively.
- **No branding-agency-style buildout.** Executive personal-branding
  agency ROI claims are unsourced marketing copy; not used as a basis for any
  decision here.
- **Subdomain-per-project, not domain-per-project.** Keeps side projects
  under one accumulating identity instead of scattering across dead domains
  Brad would otherwise have to buy and let lapse.
- **DNS/subdomain setup is a manual step for now** — no registrar/DNS API
  access has been granted, so each new project's subdomain is a ~2-minute
  manual DNS record (see HANDOFF.md checklist).
- **`jobTitle` is "VP, Data & Analytics", not "Executive" or "Senior
  Leader".** LinkedIn's 2026 recruiter-search guidance: headline/title
  carries ~60% of search ranking weight, and 87% of recruiters search by
  standard job-function titles rather than level-descriptor words like
  "Executive." A concrete, real title outranks a vaguer one.
